# Love Checklist — for Mena

A tiny shared checklist that lives in your browser toolbar. Add the little
promises you keep together, tick them off, and clear the ones you have finished.

Built for **Mena** — a small, warm gift. No tracking, no network calls, no
dark patterns: everything stays in your own browser storage.

## Features

- Add an item with the `+` button (or Enter).
- Tick an item to mark it done (strikethrough).
- Remove a single item with `×`.
- **Clear done** removes everything ticked.
- **Reset** restores the starter list.
- Live counter: `"2 of 5 done"`.
- Follows your light/dark preference.

## Install (sideload)

Works in **Chrome, Edge and Firefox** from one codebase.

### Chrome / Edge
1. Copy `manifest.chrome.json` to `manifest.json`.
2. Open `chrome://extensions` (or `edge://extensions`).
3. Turn on **Developer mode**.
4. Click **Load unpacked** and pick this folder.
5. Pin the extension and click it to open the popup.

### Firefox (temporary add-on)
1. Copy `manifest.firefox.json` to `manifest.json`.
2. Open `about:debugging#/runtime/this-firefox`.
3. Click **Load Temporary Add-on…** and pick `manifest.json`.

## Development

No build step. Plain MV3 JavaScript.

```
node --check src/common/api.js
node --check src/background.js
node --check src/popup/popup.js
node test/harness.js
```

The icons are generated by a dependency-free Node PNG encoder:

```
node tools/make-icons.js
```

## Data

Everything is stored under the single key **`mena-checklist`** as an array of
`{ id, text, done }` using `chrome.storage.local`.
